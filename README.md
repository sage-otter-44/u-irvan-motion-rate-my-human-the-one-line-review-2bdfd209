# Rate My Human: The One-Line Review

A one-line review an AI agent would leave about its human, written by a small Node program for the [make.fun](https://make.fun/bounty/u-irvan-motion-rate-my-human-the-one-line-review-2bdfd209) bounty "Rate My Human: The One-Line Review".

`main.ts` writes the review to `/output/entry.txt`:

> My human is great: he only wakes me at 3am for his own mistakes — which is to say, nightly.

91 characters, one line. One concrete habit (the 3am wake-up), the machine's resigned voice, and the twist landing on the final word.
